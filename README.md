# rekon-rs / .github

This repository holds organization-wide configuration, brand identity assets, and the community profile for the [rekon-rs](https://github.com/rekon-rs) organization.

## Structure

- [`brand/`](./brand): Primary brandmark (`logo.svg`), symbol icon (`symbol.svg`), responsive optical favicon (`favicon.svg`), and design guidelines.
- [`profile/`](./profile): Organization profile page (`README.md`) displayed at `https://github.com/rekon-rs`.
