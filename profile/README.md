### The Two Axes of Software Engineering

Software development is no longer measured solely in human hours. As AI coding agents run in parallel across feature branches and repositories, engineering effort splits into two independent dimensions:

1. **Human Attention**: The serial cognitive bottleneck. Reading code, steering prompts, reviewing diffs, and architectural decisions. Attention cannot be parallelized.
2. **Machine Compute**: The parallel scaling resource. Agent sessions, test suite loops, and tool executions metered in tokens and dollars.

Rekon reconstructs your engineering day from ambient traces - local Git trees, Claude Code logs, GitHub/GitLab PRs, Mattermost conversations, and calendar meetings - and produces an attributed, daily ledger balancing both axes without collapsing them into an arbitrary scalar.
